# Daum Finance — Market Context MVP

이슈를 **검색하는** 경험에서, 이슈를 **따라가는** 경험으로.

가격·기사·검색 관심·커뮤니티·AI 요약은 이미 존재하지만 하나의 지속적인 **시장 이슈** 객체로 연결되지 않는다는 문제를 다루는 모바일 프로토타입입니다.

**🔗 배포:** https://siegfriex.github.io/daum_tf09/

> ⚠️ 화면의 모든 수치·기사·의견은 **프로토타입 시연용 예시 데이터**이며 실제 서비스 데이터가 아닙니다.
> 시장 반응은 *같은 시간대의 관측값*으로만 표기하며 인과관계로 표현하지 않습니다.

## 핵심 화면

| 경로 | 화면 | 역할 |
|---|---|---|
| `#/money` | 머니 홈 | 기존 금융지표·종목랭킹 사이에 **오늘 시장에서 달라진 것** 삽입 |
| `#/search/samsung` | 삼성전자 검색결과 | 기존 증권정보와 AI 요약 사이에 **관련 시장 이슈** 컨텍스트 카드 |
| `#/issue/samsung-mistral` | **시장 이슈 상세** | 제품 본체. 아래 6단 순서 고정 |
| `#/news/samsung` | 뉴스 · 설명축 변화 | 기사 수 추이 + 설명축별 이전→현재→Δ, 선택 시 대표 기사 필터 |
| `#/community/samsung-mistral` | 주요 해석 | 성장 기대 / 영향 제한 / 비용 우려 / 다른 해석 |

### 시장 이슈 상세 — 정보 순서 (고정)

1. 무엇이 바뀌었나
2. 시장 반응
3. 설명축 변화
4. 관심 변화
5. 주요 해석
6. 근거 (사실 / 시장 / 언론 / 의견 구분)

### 클릭 플로우

```
검색결과 → 관련 시장 이슈 카드 → 이슈 상세 → 설명축 펼치기 → 근거 시트
머니 홈 → 오늘 시장에서 달라진 것 → 이슈 상세
뉴스   → 설명축 선택 → 관련 대표 기사
이슈   → 주요 해석 → 대표 의견 시트
```

## 설계 원칙

- **시장 반응 ≠ 원인** — 가격 변화는 동시간 관측값으로만 표시
- **관심 ≠ 중요도** — 검색·뉴스·커뮤니티를 합산한 통합 점수를 만들지 않음
- **인기 ≠ 합의** — 추천수·작성자 신뢰를 사실성으로 사용하지 않음
- **설명축 ≠ 감성분석** — 긍정/부정이 아니라 반복되는 설명 프레임의 비중 변화
- 목표주가·매수/매도 판단·투자추천 없음

디자인 토큰은 2026 다음 모바일 다크 UI의 실제 CSS custom property 값을 사용합니다
(`--bg-surface #141517`, `--bg-slot #1C1E21`, `--text-88`, `--finance-up #FF4E33` 등).

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run build      # dist/
npm run preview
```

## 배포

`main` push 시 `.github/workflows/deploy-pages.yml` 이 GitHub Actions에서 빌드하고 Pages로 배포합니다.
Vite `base` 는 `/daum_tf09/`, 라우팅은 **HashRouter** 라 deep-link 새로고침에서도 404가 발생하지 않습니다.

## 스택

Vite 5 · React 18 · TypeScript 5 · react-router-dom 6 (HashRouter) · 빌드 의존성 외 런타임 라이브러리 없음
